## Goal
Recover actual artifacts and repository/deployment references. Establish what exists without assuming sabotage, prior approval or claimed test execution.

## Work
Inspect source and Git/configuration as inert data in a restricted environment. Preserve observed files/refs before changes. Record dirty state, unknown authorship, missing logs and baseline limitations. Implement the initial exact-revision change register and path ownership for future tasks.

## Deliverables

## Acceptance gates
A controlled unapproved file/revision change is detected and blocks release. Approved baseline updates are explicit. Missing prior history produces an unknown finding, not a clean certificate. No prior source is destroyed.

## Scope and limits
audit/, docs/baseline/, change-control tooling. No production secrets, force-pushes, deployment writes or automatic code execution from unfamiliar scripts.

## Required return
Provide the patch/PR, actual changed files, base/head revision or explicit lack of Git history, executed commands and test output, sources/evidence, approval state and blockers. Stop at this task's authorization boundary; continue independent local work rather than retrying failed permissions. Do not call this task done merely because code was generated.
